**`VirtualBatterySetup.exe`** dosyasını indirin, açın, **Kur**'a basın. Yeniden başlatma gerekmez.

- Masaüstü bilgisayara Windows'un tanıdığı sanal pil ekler (Knight Online'da RDP / AnyDesk ile yönetememe sorunu için).
- Secure Boot açık kalır, Test Modu gerekmez, özel çekirdek sürücüsü yoktur.
- Pil her zaman fişe takılı görünür; bilgisayarı uyutmaz, kapatmaz.
- Kaldırınca aygıt, sürücü, sertifika ve dosyalar silinir.

---

Download **`VirtualBatterySetup.exe`**, open it, press **Install**. No restart needed.

- Adds a virtual battery that Windows recognises on a desktop PC.
- Secure Boot stays on, no Test Mode, no custom kernel driver.
- Always reports external power; never sleeps or shuts down the PC.
- Uninstalling removes the device, driver, certificate and files.

Windows 10 2004+ / Windows 11, x64.
